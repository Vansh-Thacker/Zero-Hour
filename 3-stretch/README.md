# Stretch: one extra capability

Only start here once your Foundation game works and your theme is in.

There is one guide for each capability. Each says what you start with, what counts as done, and the hard cases your build must handle. Pick one.

| Guide | In one line |
|---|---|
| `reactive-questions.md` | What the players buy in each phase changes the type and difficulty of the question they face in that phase |
| `multiplayer.md` | Players on separate devices play one shared game with one shared budget |
| `rewind-and-compare.md` | After a game, change an earlier decision and see the two outcomes side by side |
| `scenario-studio.md` | A way for our Cyber team to update the game later without writing code |

There is no extra code or data in this folder. Every capability builds on the files in `1-foundation`.
