# Multiplayer

Players on separate devices play one shared game with one shared budget.

## What you start with

The scoring module works out everything from the list of locked rounds. One place can hold that list and every device can show the result. The supplied server only serves files, so the shared part is yours to build.

## It counts when

- Two or more devices join the same game with a simple code or link. Two browser windows on one laptop count as two devices for the demo.
- Everyone sees the same budget, basket and round, and sees changes without reloading the page.
- If two players act at the same moment, the game ends up in one valid state. For example, two players spend the last of the budget at once and only one purchase goes through.
- A player who drops out and rejoins sees the game as it is now.
- Every purchase is still checked by the scoring rules.
