# The Map Room

The business is a map of connected systems. Players place their defences and watch the attacker's route across the four phases.

**The least that counts as this theme:** named business systems the player can select, an attack that visibly moves, and consequences for the player's choices.

## What is here

`reference.json` gives nine named systems with starting positions, and the attacker's route in each phase: from outside to a workstation, on to the identity service and document store, then to casework and work orders, and finally which systems are encrypted.

The route is a starting point. You decide how controls and answers change what the player sees.

## Artwork you could use

- `2-extend/artwork/map/`: 2D system nodes, markers and the attacker's route
- `2-extend/artwork/3d/map/`: a citadel model for each of the nine systems
- `2-extend/artwork/scenery/` and `2-extend/artwork/3d/scenery/`: rivers, mountains, trees and buildings
- `1-foundation/artwork/icons/`: an icon for each control
- `2-extend/worlds/`: a ready-assembled map

## Keep in mind

- Label every system by name. The map is an illustration, not a real network.
- Say whether each effect is prevention, detection or response.
- Citadel walls are scenery. They do not show that a defence is in place.
- Use the same four-round rules as the core game (see `BRIEF.html` in the pack folder).
