# The Incident Room

Live through the attack in the emails, chat, calls and updates a real employee would see.

**The least that counts as this theme:** incident updates the player can act on, status that changes with their choices, and a debrief.

## What is here

`reference.json` gives the setting for each phase: the inbox on Monday afternoon, the incident chat overnight, the phone call to the night desk, and the update as the day shift arrives.

## Artwork you could use

- `2-extend/artwork/incident/`: 2D screens for email, chat, call and recovery
- `1-foundation/artwork/everyday/`: email, laptop, phone and USB stick
- `1-foundation/artwork/icons/`: an icon for each control
- `2-extend/artwork/3d/scenery/`: desk, monitor and operator models, if you want a 3D room
- `2-extend/worlds/`: a ready-assembled Incident Room scene

## Keep in mind

- The player's choices must change what the room shows. Pictures alone are not a theme.
- Use the same four-round rules as the core game (see `BRIEF.html` in the pack folder).
- Explain prevention, detection and response accurately. Detecting something is not the same as stopping it.
