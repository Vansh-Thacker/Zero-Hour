# Extend: a theme

Everything you need to put the Foundation game into a theme. Choose one of our three ideas, or bring your own and check it with us on Saturday.

| What | Where |
|---|---|
| A guide and a starting reference file for each theme | `themes/incident-room/`, `themes/endurance-race/`, `themes/map-room/` |
| 2D artwork for each theme, plus scenery | `artwork/incident/`, `artwork/race/`, `artwork/map/`, `artwork/scenery/` |
| 3D models in GLB format: cars, track pieces, race parts, control models, map citadels and scenery | `artwork/3d/` |
| A picture of each 3D model, and overview sheets | `previews/` |
| A ready-assembled 3D scene for each theme | `worlds/` |
| Licence notices for the artwork | `licences/` |
| The artwork viewer. Open it by double-click | `artwork.html` |

All the artwork is optional. Use it, change it or make your own. The house style is a default, not a rule.

A picture is not a game mechanic. A wall on the map or a marker on a system does not show that a defence works. Your game's rules decide that.
