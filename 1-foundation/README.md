# Foundation: the core game

Everything you need for the core game, with the behaviour questions built in. Read `BRIEF.html` in the pack folder first.

| What | Where |
|---|---|
| The demo page. Open it with `npm start` from the pack folder | `demo.html` |
| The scoring code for control purchases | `starter/controls.mjs` |
| The local web server | `starter/serve.mjs` |
| Tests for the scoring code and the data | `tests/` |
| The scenario: budget, 18 controls, 3 already in place, 4 phases | `data/challenge.json` |
| The 40 behaviour questions | `data/questions.json` |
| A small made-up scenario the tests use | `data/fixture.json` |
| An icon for each control | `artwork/icons/` |
| Pictures of everyday items for the questions: email, laptop, phone, USB stick | `artwork/everyday/` |
| The ScottishPower brand mark | `artwork/brand/` |

How the code and data work is in `README.md` in the pack folder.
